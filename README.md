# Quantum Search Using Grover's Algorithm

## 1. Project Overview
This project demonstrates quantum search using Grover's
algorithm and Qiskit.

The objective is to understand how a quantum oracle marks
a target state and how Grover's algorithm increases the
probability of measuring that state.

## 2. Objective
To implement a simple quantum search circuit and observe
its measurement results using a quantum simulator.

## 3. Tools Used
- Python
- Qiskit
- Quantum circuit simulator

## 4. How the Algorithm Works
1. Initialise the quantum registers.
2. Apply Hadamard gates to create a superposition.
3. Apply an oracle to mark the target state.
4. Apply the Grover diffusion operator.
5. Measure the qubits.
6. Observe the measurement results.

## 5. How to Run
1. Install Python.
2. Install the required Qiskit packages.
3. Open the Python file or Jupyter notebook.
4. Execute the code.
5. Observe the circuit and measurement results.

## 6. Results
The simulator produces measurement outcomes.
The results illustrate how Grover's algorithm increases
the probability of measuring the marked state.

Actual results depend on the circuit and its parameters.

## 7. Limitations
This demonstration uses a simulator and does not,
by itself, establish quantum advantage over classical search.
