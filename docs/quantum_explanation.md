# Understanding Grover's Search Algorithm

## 1. Objective
Search for a target number among five input numbers
using Grover's quantum search algorithm.

## 2. Binary Representation
Four qubits represent 16 possible numbers,
from 0 to 15.

## 3. Superposition
Hadamard gates place the four data qubits into
an equal superposition of 16 candidate values.

## 4. Oracle
The oracle marks a candidate when it belongs to
the input list and equals the target.

## 5. Diffusion Operator
The diffusion operator amplifies the probability
of the marked candidate.

## 6. Measurement
The quantum state is measured, producing a
classical bitstring that represents a number.

## 7. Important Note
This project uses a classical simulator to
demonstrate Grover's algorithm. It does not
demonstrate a quantum hardware speed advantage.
